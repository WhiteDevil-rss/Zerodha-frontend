# Zerodha Frontend

This is the frontend React application for the project.

## Prerequisites

- Node.js (v18 or higher recommended)

## How to Run This Project

Follow these step-by-step instructions to get the project running on your local machine:

### 1. Install Dependencies
Navigate into this `Zerodha-frontend` directory and install all the required npm packages:
```bash
npm install
```

### 2. Run the Application
Start the development server:
```bash
npm start
```
The server will start, and the application will be automatically opened in your browser at [http://localhost:3000](http://localhost:3000).

### 3. Initialize Database (Note)
*Note: Since this is the frontend part of the application, there are no database initialization steps here. If you need to initialize dummy data for the database (like `init/index.js`), please ensure you do that in the backend directory of your project before attempting to interact with data-driven components in this frontend.*
